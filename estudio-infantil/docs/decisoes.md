## Decisões estruturais

| Decisão | Escolha | Justificativa |
|---|---|---|
| Faixa etária | **3–6 anos** | Maior volume de audiência e menos concorrência que 0–3. Vocabulário e ritmo já suportam narrativa. |
| Formato base | **Série narrativa com refrão musical recorrente** | A história sustenta a retenção; o refrão fixo cria reconhecimento e reuso entre episódios. |
| Duração | **Episódio 4 min (3–5) + compilado mensal 45–60 min** | O episódio alimenta a frequência; o compilado sustenta o watch time. |
| Estilo visual | **2D flat** | Barato, consistente entre gerações de imagem, escalável. |
| Idioma-mãe | **PT-BR** | Ordem de expansão: PT-BR → ES-LA → EN-US → HI → ID. |
| Pilar pedagógico | **Emoções + rotina** | Maior busca dos pais; gera séries longas sem repetir conceito. |

## Decisões derivadas

| Item | Escolha |
|---|---|
| Marcação no YouTube | Todo vídeo marcado como "feito para crianças" |
| Cadência | 1 episódio/semana × 5 idiomas + 1 compilado/mês por idioma |
| Estrutura obrigatória | Gancho → Situação → Tentativa falha → Virada → Resolução → Refrão → Ponte |
| Checkpoints humanos | (1) aprovação do roteiro, (2) aprovação do corte final |
| Canal paralelo para pais | A partir do dia ~76 (não marcado como infantil) |
